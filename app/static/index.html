Alur Pipeline Information Retrieval

  1. Crawling Mandiri: WordPress REST API dari BasaBasi.co (483 cerpen) dan BacaPetra.co (197 cerpen) — total 680 cerpen unik.
  2. Duplicate Checking 3 Lapis: Normalisasi URL, SHA-256 Hash, dan TF-IDF Cosine Similarity (≥ 0.95).
  3. Custom Preprocessing: Pembersihan HTML & tanda baca sastra, custom stopwords domain fiksi, serta Sastrawi Stemmer.
  4. PyLucene 9.12 Indexing: WhitespaceAnalyzer (Custom) vs StandardAnalyzer (Baseline) dengan Term Vectors aktif.
  5. Retrieval & Feedback: BM25 (k1=1.2, b=0.75), TF-IDF Klasik (ClassicSimilarity), Query Expansion, dan Rocchio Algorithm.

Rumus Matematika Model & Parameter

1. Okapi BM25 (PyLucene BM25Similarity)
Score(D, Q) = Σ IDF(q_i) · [f(q_i, D) · (k1 + 1)] / [f(q_i, D) + k1 · (1 - b + b · |D|/avgdl)]

Parameter: k1 = 1.2, b = 0.75, bobot judul 2.0×.

2. TF-IDF Klasik (PyLucene ClassicSimilarity)
Score(D, Q) = coord(Q, D) · queryNorm(Q) · Σ [sqrt(tf) · idf(t)^2 · norm(t, D)]

Model Vector Space berbasis pembobotan frekuensi term & normalisasi panjang dokumen.

3. Rocchio Relevance Feedback
q_m = α·q_0 + (β/|D_r|)Σ d_r − (γ/|D_nr|)Σ d_nr

Default: α = 1.0, β = 0.75, γ = 0.15 di atas Term Vectors Lucene.
